# Portfolio

Personal website of Maria Alejandra Lizarazo: https://malelizarazo.github.io/Portafolio/

Built with Next.js (static export), React, TypeScript, Tailwind CSS and Three.js (animated molecular scene in the hero).
Deployed to GitHub Pages by the workflow in `.github/workflows/deploy.yml` on every push to `main`.

## Run locally

```bash
cd portfolio
npm ci
npm run dev
```

Open http://localhost:3000/Portafolio.
